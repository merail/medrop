# MeDrop

A Chrome extension that sorts downloaded files into folders based on file extension, with support for exclusions and a default catch-all folder.

## Installation

1. Open `chrome://extensions`.
2. Enable "Developer mode".
3. Click "Load unpacked" and select this folder.
